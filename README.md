# BECO — Plataforma de inteligência imobiliária

> Nome provisório até a conclusão da pesquisa de anterioridade e viabilidade de registro.

O BECO transforma informação imobiliária dispersa em inteligência organizada, rastreável e acessível. O primeiro foco é o mapeamento de **HIS** (Habitação de Interesse Social) e **HMP** (Habitação de Mercado Popular) no Município de São Paulo, com classificação separada para os demais segmentos, como studios de livre comercialização.

## Regras de trabalho

- Nenhuma fase é pulada; cada uma termina com entregáveis, decisões, alternativas descartadas, pontos de validação e próximos passos.
- Decisões irreversíveis (nome, identidade, arquitetura de dados, integrações com custo) dependem de aprovação do responsável.
- Nenhum dado é inventado. Fatos têm fonte; hipóteses são marcadas como hipóteses.
- Dados de demonstração, quando usados, são identificados como fictícios e nunca se misturam a dados verificados.
